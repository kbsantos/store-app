# Store Dashboard Controls Update

## Changes
- Date range controls (`FROM` and `TO`) are aligned on the left side of the filter card.
- Reporting Integrity and View PDF actions are icon-only buttons on the right.
- Added tooltips for both icon actions.
- Integrity loading state remains visible as a progress indicator.
- Responsive fallback uses a wrap on narrow layouts.
